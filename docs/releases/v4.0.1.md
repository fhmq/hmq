# HMQ v4.0.1

This patch fixes consumer isolation, connection admission and MQTT 5 delivery
selection, and removes full-payload serialization from the size preflight.

## Fixes

- Require Go 1.27.4 in source builds, CI and the container builder, and upgrade
  `github.com/klauspost/compress` to v1.20.2, addressing the newly published
  GO-2026-6859 and GO-2026-6865 advisories. The unused openpgp module-level
  advisory disclosed in previous releases remains outside imported packages.

- Disconnect an MQTT 5 consumer when its bounded outbound queue fills, without
  propagating that consumer's queue error to unrelated publishers. Their QoS1
  acknowledgments and healthy subscriptions continue to progress.
- Try another shared-subscription member when the selected consumer cannot
  accept the packet size, or its waiting queue is full. An oversized ordinary
  subscriber delivery remains a local discard, without consuming inflight credit.
- Bound pending CONNECT and TLS handshake I/O with a read/write deadline, and
  bound admitted client connections globally and per socket peer IP. Release
  admission counters on disconnect and clear the deadline after CONNECT parsing.
- Bound WebSocket HTTP header reads. Pre-upgrade HTTP connection admission still
  requires reverse-proxy or firewall controls.
- Replace MQTT 5's full serialization to `io.Discard` with a size-only preflight.
  Queued messages are encoded for transmission only when they can be sent.

## Configuration

New optional fields: `connectTimeoutSeconds` (default 10), `maxConnections`
(default 10000), and `maxConnectionsPerIP` (default 256). Zero selects the
defaults; negative values are rejected. These finite defaults apply to existing
configurations too. Raise limits deliberately when deploying behind a shared
proxy or supporting more clients. See `broker/MQTT5.md` for scope and caveats.

The Go module remains `github.com/fhmq/hmq/v4`. Existing MQTT 5 profile and
experimental quorum limitations are unchanged. This release also includes the
dependency updates already merged into master after v4.0.0.

## Verification

- Regression for the former 258th-publication publisher disconnect.
- Deterministic shared-member fallback and size-preflight allocation regression.
- Global/per-IP admission, slot release, CONNECT timeout and cleared-deadline tests.
- Full uncached race-enabled tests, static analysis and vulnerability scan.
- Release workflow validates container startup and builds five platform archives
  with SHA256 checksums; consult the published workflow and assets for completion.
